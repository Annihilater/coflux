# Coflux 2.20.1

**Agents in Coflux terminals can clean up their own git worktrees again.**

Inside a Coflux terminal, Claude Code runs a hook that stops an agent from removing or moving a git worktree that Coflux tracks as a workspace, because doing that with git directly leaves a stale workspace in the sidebar. Until this release the hook refused every `git worktree remove` and `git worktree move` in a Coflux project, including the many worktrees Coflux has no record of. Agents cleaning up worktrees they had created themselves, or pruning branches whose remote is gone, were turned away over and over.

In 2.20.1:

- The hook blocks a worktree removal or move only when its target is a worktree that Coflux has registered as a workspace on this device. Every other worktree is left to git.
- It works out the target the way git does, by path or by a unique trailing part of its path. It then asks the local Coflux service on this device whether that worktree is a workspace, so the check needs no network.
- When it blocks, the message names the workspace and the command to use instead, `coflux workspace remove <workspaceId>`, which closes that workspace's terminals and then removes the worktree and its sidebar entry. If the agent's own terminal belongs to that workspace, the message says so.
- When the hook cannot tell for sure, it stays out of the way. That covers a target built from shell variables or globs, and a Coflux service that does not answer in time.
- The phrase quoted inside a commit message or an `echo` no longer counts as a command.
- The Claude Code plugin moves to 0.23.0. Its separate Node script for this check is gone; the `coflux` command line tool now does the check for both the plugin and the managed agent integration.

## Install or update

**Mac:** install `coflux-2.20.1-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.20.1
cofluxd update
```

## Upgrade impact

- The fix lives in the `coflux` command line tool that Coflux puts on the path of its terminals. On a Mac, update the desktop app; on a headless host, install `cofluxd@2.20.1` and run `cofluxd update`.
- An agent session that is already running keeps the old check until it is restarted. Start a new Claude Code session in a Coflux terminal to get the new one.
- Removing a registered workspace's worktree is still blocked, as before; use `coflux workspace remove`.
- No center, protocol or configuration change.
