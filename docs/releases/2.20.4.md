# Coflux 2.20.4

**Agents in a Coflux terminal read about half as much when they load the coflux skill.**

The coflux skill teaches Claude Code and Codex how to use Coflux terminals, progress, notifications and the account CLI. It used to be a single 44 KB file, and an agent loaded all of it even for a one-line `coflux progress`. That cost context space and tokens in every session.

In 2.20.4:

- The skill's main file now holds only what almost every session needs: where the agent is, opening and driving terminals, progress, notifications, preview URLs and errors. It is about half its previous size.
- Workspaces and worktrees, entity handles, the executor, annotations and the account CLI each have their own file next to it, and an agent reads one only when the task calls for it.
- Nothing was removed from what the skill teaches; every command, limit and error message is still documented.
- The bundled Claude Code plugin is now 0.25.0.

## Install or update

**Mac:** install `coflux-2.20.4-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.20.4
cofluxd update
```

## Upgrade impact

- An agent that is already running keeps the skill it started with. Relaunch Claude Code or Codex in a Coflux terminal to pick up the new one; open terminals do not need to be closed.
- A headless host that already runs the launcher receives the new version automatically. `cofluxd update` does it immediately.
- No center, protocol or configuration change.
