# Coflux 2.19.2

**A remote screen keeps working after you resize it or close and reopen it.**

In 2.19.0 and 2.19.1 a remote screen worked for the first session on a Mac and then broke: resizing the view froze the picture behind a "preparing the display" spinner, and closing the view and opening it again failed with "virtual display did not come online", every retry included, until that Mac's Coflux runtime restarted. The screen helper on the controlled Mac never heard about display changes macOS made after its first session, so it kept waiting for displays that were already there.

In 2.19.2:

- The screen helper follows every display change, so resizing the view, switching resolution presets and reopening a closed screen keep streaming on the same Mac without restarting anything.
- Rapid resizes no longer race each other: the newest size wins and older attempts stop touching the display.
- If preparing the remote display does fail, the view shows the connection-failed state with a Retry button instead of an endless spinner, and the controlled Mac is left with no invisible extra display. While the error is shown, that Mac can sleep and lock as usual again.
- The controlled Mac's log records each failed attempt and each display change, and the failure message no longer blames sleeping displays unless they really are asleep.

## Install or update

**Mac:** install `coflux-2.19.2-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.19.2
cofluxd update
```

## Upgrade impact

- Update the desktop app on both Macs: the fix lives in the screen helper that ships with the app on the Mac being controlled, and the Retry state needs the new app on the controlling Mac. A screen session that is open while the app updates keeps the old helper until it ends.
- Headless hosts gain nothing from this release and need no action.
- No center, protocol or configuration change.
