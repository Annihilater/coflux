# Coflux 2.19.1

**Devices show their operating system, so a device and its screen no longer look alike.**

Since 2.19.0 a device's open screen is listed in the sidebar right under the device, and both used the same monitor icon. Devices now carry their operating system's mark instead: the Apple mark for Macs, the Linux penguin for Linux machines, and a generic server icon for anything the app does not recognise. The monitor icon now means only a remote screen.

In 2.19.1:

- The new marks appear wherever a specific device is shown: the sidebar device rows, the device tooltip, the device line in a workspace's hover card, device entries in the command palette, and the device list when importing a project. The settings section for this machine shows the Apple mark.
- The device tooltip names the system in words, for example `my-mac · macOS` or `build-box · Linux`, instead of the raw platform string.
- With no devices yet, the sidebar's "add your first device" button shows a plus.
- Devices enrolled long ago that still report `darwin` are shown as Macs.

## Install or update

**Mac:** install `coflux-2.19.1-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.19.1
cofluxd update
```

## Upgrade impact

- Desktop only: update the app to see the new icons. Headless hosts gain nothing from this release and need no action.
- No center, protocol or configuration change.
