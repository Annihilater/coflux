# Coflux 2.12.0

**See and drive a remote Mac from a screen tab, watch executor runs on the terminal that started them, annotate pages with far more precision, and download releases quickly from mainland China.**

The center, the runtime and the desktop app all change. The center was updated before this release was published.

## Highlights

- **Remote screen tabs.** Open a remote Mac's screen from the device page's new-tab menu, the sidebar device menu or the command palette. You get the picture with keyboard and mouse control, a two-way clipboard for text and images, a virtual display so a Mac with its lid closed still has a screen, and idle-lock prevention. While the picture has focus every key combination goes to the remote Mac, except Control-Option-Command-F, which toggles immersive mode. If the remote Mac is missing Screen Recording or Accessibility permission, the tab names the missing one and the remote Mac shows the system request. The controlled side must be a Mac running the Coflux desktop app on macOS 26 or later.
- **Executor runs in a picture-in-picture card.** A run started with `coflux executor run` now appears as a small card on the terminal that started it, on every device, with its latest log lines. Drag it to any corner, click it to expand into the full conversation, and stop the run with one click. The card disappears when the run ends unless it is expanded. `coflux executor run` gains `--title` to name the run.
- **Precise browser annotations.** Annotating works like a design tool: Command-Shift-D enters and leaves annotate mode without resizing the page, the Up arrow selects the containing element, Shift-click gathers several elements into one annotation, Shift-drag annotates a region, and deletions can be undone. The side panel groups annotations by page, and agents see every element and region of an annotation.
- **Easier-to-read text.** No text in the desktop app is smaller than 11 px any more; body text is 13 px and secondary text 12 px.
- **Fast downloads from mainland China.** The latest stable release is now served from `https://dl.coflux.dev`, a Cloudflare-backed mirror, instead of GitHub Releases, which is very slow or unreachable from mainland China. This covers runtime hot upgrades, `cofluxd up` and `cofluxd update`, desktop app updates, and the desktop download on the add-device page. GitHub Releases are still published and remain the archive for every older version.

## Install or update

**Mac:** install `coflux-2.12.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.12.0
cofluxd update
```

## Upgrade impact

- **Existing browser annotations are cleared.** Annotations now carry several elements and an optional region, and the new runtime does not read the old format. Update the desktop app and the runtime on the device that hosts the workspace together.
- **Remote screen tabs need a runtime restart on the controlled Mac.** A runtime that was already running when the app updated does not know about the new screen helper, so the screen entry does not appear for that Mac until its runtime is restarted from the desktop app.
- **Command-Shift-D is a new shortcut** in the built-in browser, where it toggles annotate mode.
- **`coflux executor run` summaries change.** The summary is now the last assistant message only, instead of every message joined together.
- **`cofluxd update` without `--version` installs the latest stable release.** It no longer picks up prereleases. Any older version or prerelease still installs with `--version vX.Y.Z`, downloaded from GitHub Releases.
- The first desktop update served from the mirror downloads in full; later updates can download only the changed parts again.
- No schema migration and no new server configuration.
