# Coflux 2.14.0

**Review a workspace's changes like a code review, comment on diff lines for your agent, open terminal file paths in a tab, and launch your coding agents from the new-tab menu.**

The center needs no update. Daemons pick up the new runtime through the usual hot upgrade; update the desktop app to use the new review features.

## Highlights

- **A review-grade changes view.** The changes overlay now compares either everything on the branch or only uncommitted work, emphasises the changed words inside a changed line, and steps through changes across files with F7 and Shift-F7 (hold Fn on a Mac keyboard). Files carry type icons, a right-click menu copies paths or reveals a local file in Finder, and a filter box above the tree (Command-F) narrows it by path. A file with only additions or only deletions is always shown inline.
- **Choose how whitespace counts.** A whitespace menu in the diff header picks one of four modes: show every change, ignore trailing whitespace, ignore changes in the amount of whitespace, or ignore all whitespace. Word emphasis follows the same mode.
- **Comment on diff lines and hand the comments to your agent.** Click the gutter or drag across lines to leave a comment, then use "Hand off to agent" to send every pending comment to a Claude Code or Codex terminal in the workspace. Agents see them in `coflux annotations list` with the file, line range and quoted lines, and resolve them when done.
- **Terminal file paths open in a tab.** Hovering a path that exists in the workspace colours it; Command-click opens the file in a read-only tab at the referenced line, and opening the same file again focuses that tab. The tab follows changes on disk and survives a restart. Right-click a path to open or copy it.
- **Launch Claude Code, Codex, Cursor or Grok from the new-tab menu.** Turn agents on in Settings > Agents and give each its launch command; Command-T then offers an Agent submenu that opens a terminal named after the agent and types the command once.
- **Secrets for agents, including multi-line values.** Agents are steered to `coflux secret` whenever a value must stay out of the transcript, through a dedicated `coflux-secret` skill. The secret card on desktop and iOS now accepts pasted multi-line values such as private keys and JSON credentials.

## Install or update

**Mac:** install `coflux-2.14.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:**

```sh
npm install -g cofluxd@2.14.0
cofluxd update
```

## Upgrade impact

- **Command-click on a terminal file path now opens it** instead of copying it; copying moved to the right-click menu. Terminal links no longer underline on hover.
- **New keys in the changes view:** F7 and Shift-F7 step between changes, and Command-F focuses the file filter.
- **Update the runtime and the desktop app together.** The new scope, whitespace modes, diff comments and file tabs need the 2.14.0 runtime; against an older daemon the desktop shows an update hint for each of them instead. An older desktop app shows diff comments made from 2.14.0 as cards without a target in its browser panel.
- **Agent integration:** the Claude Code plugin moves to 0.21.0 with the new `coflux-secret` skill; the managed Codex integration updates the next time the agent is launched.
- **Known limitation:** multi-line secret values are not masked in terminal output yet.
- The desktop renderer now runs React 19.3 with the React Compiler applied to the whole workbench.
- No schema migration and no server configuration change.
