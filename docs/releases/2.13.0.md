# Coflux 2.13.0

**A desktop-only release: the sidebar collapses out of the way with Command-B, and executor cards move like picture-in-picture.**

Nothing in the center or the runtime changes. Install the desktop app; daemons on other machines need no action.

## Highlights

- **Collapsible sidebar.** Press Command-B, or use the new item in the View menu, to hide the sidebar and give the terminals the full window width. A button next to the window controls brings it back, and pressing Command-N while it is hidden opens it together with the new-workspace menu. The window can still be dragged by its tab strip while the sidebar is hidden, and the collapsed state is remembered per machine.
- **Executor cards move like picture-in-picture.** Throw a card toward any corner and it springs there; catch it mid-flight to redirect it. Several runs started from one terminal stack into a deck you can flip through, and expanding a card morphs it into the full conversation panel and back. A card springs away when its run ends. With macOS "Reduce motion" turned on, cards move without animation.

## Install or update

**Mac:** install `coflux-2.13.0-arm64.dmg` from `https://dl.coflux.dev/desktop/coflux-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:** this release contains no runtime changes, so there is nothing to update. The packages are published at the same version for consistency:

```sh
npm install -g cofluxd@2.13.0
cofluxd update
```

## Upgrade impact

- **Command-B is a new shortcut** that toggles the sidebar. Inside a built-in browser page it stays with the page (for example, bold in a web editor); the View menu item still works there.
- No schema migration, no server configuration, and no daemon capability is involved. A machine running 2.12.0 daemons works unchanged with the 2.13.0 desktop app.
