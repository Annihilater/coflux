# Coflux 2.9.0

**A desktop-only release: the tab strip drags the window again, and the browser tab's new tab page is quieter and remembers where you have been.**

Nothing in the center or the runtime changes. Install the desktop app; daemons on other machines need no action.

## Highlights

- **The top tab strip moves the window again.** Since 2.6.1, pressing on empty space in the tab strip along the top of the window no longer dragged the window. The 2.6.1 fix that made menus opened from the tab strip clickable excluded every pop-up layer from the title bar area, and that also caught the notification area that stays open along the bottom edge of the window. The exclusion now applies only to menus and tooltips opened from the tab strip itself. Empty space in the strip drags the window and double-clicking it follows the macOS title bar setting, while the plus menu and the branch menu stay clickable.
- **A quieter new tab page with recent visits.** A new browser tab no longer shows a boxed icon, a heading and instructions that the tab strip and the focused address bar already give. It lists the workspace's forwarded ports and your five most recent visits as one-click rows; with neither, it shows a single centered hint.
- **No focus ring around the address bar.** The browser tab's address bar no longer draws a focus border, and components that opt out of the default focus ring now actually do.

## Install or update

**Mac:** install `coflux-2.9.0-arm64.dmg`, or use the desktop app's update action. The desktop app requires macOS 26+ and Apple Silicon.

**Linux or headless hosts:** this release contains no runtime changes, so there is nothing to update. The packages are published at the same version for consistency:

```sh
npm install -g cofluxd@2.9.0
cofluxd update
```

## Upgrade impact

None. No schema migration, no server configuration, and no daemon capability is involved. A machine running 2.8.0 daemons works unchanged with the 2.9.0 desktop app.
