Coflux 私有中心 2.19.1-private.1

这个包只装 Debian 上的中心。证书在安装时按这台机器的公网 IPv4 现签，包里没有私钥。
客户端要另外用同一把 CA 和这个地址编译，见 README.md 第 6 节。不要使用作者发布的桌面或 npm 上的 cofluxd。

1. 云安全组放行 tcp/22、tcp/8443、tcp/8444、udp/3478。不要放行 80、443、5432、8787、8793。
2. 把这个 tar 拷到服务器，例如 /root。
3. 在服务器上：

   umask 077
   tar -xzf coflux-private-centre-2.19.1-private.1.tar.gz
   cd coflux-private-centre
   sha256sum -c SHA256SUMS
   PUBLIC_IP=你的公网IP bash server/install.sh

   省略 PUBLIC_IP 时，脚本会尝试探测公网地址。探测到的地址如果不是你要对外公布的那一个，停掉重跑并写上正确的 PUBLIC_IP。

4. 建号：

   COFLUX_USER_EMAIL=you@example.com /usr/local/sbin/coflux-create-user

5. 把安装结束时打印的 ca.crt 拷回你的电脑，再按 README.md 编译桌面和 cofluxd。
